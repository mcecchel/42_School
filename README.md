# NetPractice — 42 Project

NetPractice è un esercizio di networking della **Piscine / Common Core di 42**, pensato per introdurre i concetti fondamentali delle reti IP.  
Il progetto consiste nel risolvere scenari interattivi in cui è necessario configurare correttamente indirizzi, subnet mask, routing e collegamenti tra host e router.

## 🎯 Obiettivi del progetto
- Comprendere l’indirizzamento IPv4  
- Usare correttamente subnet mask e CIDR  
- Calcolare network, broadcast e range degli host  
- Configurare routing tra sottoreti  
- Sviluppare un approccio sistematico al troubleshooting di rete

## 📚 Risorse utili
- Tool di Subnet Calculator  
- Documentazione Cisco sul subnetting
