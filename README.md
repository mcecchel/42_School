libft è una libreria di funzioni in C realizzata nell’ambito del curriculum della Scuola 42. Lo scopo del progetto è ricreare da zero una serie di funzioni standard della libc, esercitando:

    - Gestione della memoria: allocazione, deallocazione e controllo degli errori.

    - Manipolazione delle stringhe: copie, confronto, ricerca e formattazione.

    - Strutture dati base: implementazione di liste collegate.

    - Controllo degli input: funzioni di parsing e validazione.

Funzionalità implementate

    > Funzioni di carattere e stringa

        ft_strlen, ft_strcpy, ft_strdup

        ft_strncmp, ft_strchr, ft_strjoin

    > Funzioni di memoria

        ft_memset, ft_bzero, ft_memcpy, ft_memmove, ft_memcmp

    > Funzioni di conversione e utilità

        ft_atoi, ft_itoa

        fttoupper, ft_tolower

    > Liste collegate

        t_list come struttura dati

        ft_lstnew, ft_lstadd_front, ft_lstdelone, ft_lstclear, ft_lstiter, ft_lstmap
